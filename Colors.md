# MapChests colours and icons

The current values from `kaitorque.MapChests.cfg` (VP profile). Each colour shows a name and its hex code; the config uses the hex code.

- **Highlight**: the outline colour in the world. A dash means the category is never highlighted.
- **Map**: the minimap icon colour. Used icons turn gray (808080) unless the table says otherwise.
- **Your choice**: write the colour (a name from the palette at the bottom is fine) and icon you want. Leave a cell empty to keep the current value.

Notes:
- **Equipment multishop**: the new default is orange (FF8001), but your file still has cyan.
- **Pressure plate**: gray, the same as a used icon, so on the map it always looks used.
- **Mimic**: looks exactly like a normal chest until it reveals itself, then it shows as an enemy.
- **Secret chest**: normal chests the game places in hidden spots. **Hollow chest**: the Concept Reliquary (free, gives a Hex item).
